## 为什么单独放一个目录

因为初稿里存在**会答错药、答错病原**的错误。见 [`../数据校准说明.md`](../数据校准说明.md) 第四节"重大纠错清单"：

| 记录 | 初稿写的 | 校准结论 |
|---|---|---|
| 马铃薯晚疫病 | 推荐**甲霜灵** | 2024 全国抗药性监测：甲霜灵高抗菌株 >80%，**主产区应停用**，改用烯酰吗啉/氟菌·霜霉威/氰霜唑/氟啶胺/氟噻唑吡乙酮轮换 |
| 桃细菌性斑点病 | 病斑**直径 2 cm** | 叶斑约 **2 mm**、果斑约 **1 mm**；且农用链霉素国内已限用，应以中生菌素/春雷霉素替代 |
| 番茄细菌性斑点病 | 病原写作**黄单胞杆菌**、发病条件"高温高湿 25–30 ℃" | 实为 *Pseudomonas syringae* pv. *tomato*（bacterial speck），且**偏好冷凉 16–24 ℃** —— 初稿的温区方向是反的 |
| 葡萄叶枯病 | 与 **Esca 黑麻疹**混为一谈 | 实为 *Pseudocercospora vitis* 引起的叶部斑点病，不侵染果实 |
| 苹果黑星病 | "富士、嘎啦较**抗**病" | 富士、嘎啦系实际**感**病 |

## 给维护者的硬性约定

1. **入库只读 `../作物病害知识库_校准版.json`**，不要读本目录的 PDF；
2. 本目录 PDF 的用途只有两个：**人工对照**（看某条被改成了什么）与**留档**（追溯修订前的原文）；
3. 若发现校准版有疑问，**先查 [`../数据校准说明.md`](../数据校准说明.md) 的对应条目与 `sources`**，
   确认是校准版的问题再动数据 —— 不要回退到初稿的表述；
4. 初稿 PDF 是 ReportLab 导出、**无 PDF 书签**，且部分单元格在分页处被截断
   （如"苹果黑星病/生态防治"结尾停在"④ 保护和利用瓢"）。这也是它不适合当数据源的另一个原因。

> 目录名"初稿_勿入库"是有意为之：让 `git status` / 目录树一眼就能看出哪些文件不许当数据源。
