### Release 正文（直接粘贴）

````markdown
## 这是什么

线上系统（[crop-disease-system](https://github.com/shiguangiliushi/crop-disease-system)）实际使用的
YOLO 检测权重，覆盖 **39 个植物叶片病害类别**。

- 文件：`best.pt`
- 大小：**6,264,483 字节（5.97 MB）**
- SHA256：`F86C031BA32280423B918B62E0DCF908E4F0C067ED5891AF920709B59495584A`

## 实测指标

在同一数据集的验证集（**4528 张**）上实测，CPU、`imgsz=640`：

| 指标 | 值 |
|---|---|
| Precision | **0.8777** |
| Recall | **0.8959** |
| mAP50 | **0.9149** |
| mAP50-95 | 0.9149 |
| 推理速度 | 131 ms/张（CPU） |

> ⚠️ 两个必须知道的前提（详见仓库 `docs/评估方法.md`）：
> 1. 该数据集**每张图只有一个覆盖整图的框**（抽查 200 个标签，宽高中位数均为 1.0），
>    所以 `mAP50` 与 `mAP50-95` 必然相等，这里的 mAP 实质上是**分类准确率**；
> 2. val 与 train **同源**（PlantVillage 派生、单叶片、纯色背景），
>    真实田间照片的精度会明显低于上表。

## 用法

```python
from ultralytics import YOLO

model = YOLO('best.pt')
results = model.predict('leaf.jpg', imgsz=640, conf=0.25)
print(results[0].names[results[0].probs.top1])   # 检测任务请用 boxes.cls
```

放到线上系统里时，直接替换：

```
backend/api/newmodels/best.pt
```

后端启动时会校验类名与词条映射（`python manage.py check_model_labels`），
**权重里的类名是唯一权威**，与词条错位会导致"框上 A、详情 B"且全程静默。

## 训练方式

见仓库 README 与 `docs/评估方法.md`：
数据清洗 → 切分 → 生成 39 类配置 → Ultralytics 8.3.143 训练（Colab，GPU）。
本地 CPU 的三次实验（6 / 44 / 135 epoch）**未收敛**，仅用于验证流水线，不作为模型效果依据。
````
