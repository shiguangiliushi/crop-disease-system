## 六、失败排查表

| 报错 | 原因 | 处理 |
|---|---|---|
| `Repository not found` | 仓库没建，或建在了 `shiguangliushi` 下 | 确认浏览器登录的是 `shiguangiliushi`，重建 |
| `could not read Username` / 无登录弹窗 | 凭据管理器没有凭据 | `git config --global credential.helper manager` 后重试，或改用 SSH |
| `Permission denied (403)` | 登录账号不是仓库所有者 | 看右上角头像下拉里的用户名 |
| `src refspec main does not match any` | 分支名不是 main | 本仓库已是 main，不应出现 |

SSH 备选：

```powershell
git remote set-url origin git@github.com:shiguangiliushi/crop-disease-training.git
git push -u origin main
```
